BuberkaSmart Agent Connector

Odoo'nuzu yapay zeka ile konuşturun — veriniz tesisten çıkmadan

BuberkaSmart ERP-üstü yapay zeka veri ajanını Odoo'nuza bağlar. Doğal dilde sorun — "Bugün hangi siparişler açık?", "Ödenmemiş faturalar?" — ajan verinizi analiz edip özetler, sizi uyarır.

🔒 Salt-okuma (KVKK güvenli)

Ajan yalnızca okur — hiçbir şey yazmaz, silmez. Veriniz Odoo'nuzda kalır.

⚡ SSH gerekmez

Uygulamayı yükleyin, Ayarlar > BuberkaSmart Agent'tan bağlantı anahtarınızı yapıştırın. Teknik bilgi gerektirmez.

Nasıl çalışır?

  1. Uygulamayı Odoo'ya yükleyin.
  2. BuberkaSmart panelinden bağlantı anahtarınızı kopyalayın.
  3. Ayarlar > BuberkaSmart Agent'a yapıştırın, kaydedin.
  4. Hepsi bu — ajan artık Odoo verinize bağlı.
